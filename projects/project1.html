Project Overview & Problem Solved

Sharing or archiving TikTok content often suffers from compressed video quality, intrusive watermarks, or inability to save multi-photo slideshows and background music directly within messaging apps.

AIO-down solves this by providing an instant Telegram bot interface (@paws_down_tiktok_bot). Users simply paste any TikTok link into the chat, and the bot automatically detects whether the post is a video or photo slideshow, fetches the highest-resolution watermark-free stream, and delivers it directly to Telegram with an interactive inline button for MP3 audio extraction.

Technology Stack

Python 3 pyTelegramBotAPI (TeleBot) Flask (Keep-Alive Server) Requests (HTTP Streaming) Multi-threading TikWM & LoveTik REST APIs

Key Technical Features

  • Dual-Provider Failover Controller: Prioritizes TikWM API for full HD video and photo slide support, and automatically falls back to LoveTik API with browser User-Agent emulation if the primary provider fails.
  • Auto Content-Type Detection: Seamlessly distinguishes between single HD videos and multi-image slideshows (sending up to 10 photos as a grouped Telegram media album via InputMediaPhoto).
  • On-Demand MP3 Audio Extraction: Caches media audio URLs by video ID and attaches an inline callback button (🎵 Tải Nhạc (MP3)) so users can extract background music in one tap.
  • In-Memory Streaming & Telegram Size Guard: Streams video payloads in RAM and validates Content-Length against Telegram's 48MB bot upload limit, providing a direct download fallback link for oversized videos.
  • Real-Time 3-Step Progress Updates: Edits status messages dynamically (Connecting → Downloading → Uploading) and cleans up temporary status messages upon completion.
  • Cloud Keep-Alive Web Server: Runs a lightweight background Flask HTTP server on a separate daemon thread (port 8080 / $PORT) for cloud PaaS health checks (e.g., Render).
