Project Overview & Problem Solved

Vietnamese universities under the credit-based training system use differing conversion scales from the 10-point scale to letter grades (A+, A, B+, B...) and the 4.0 GPA scale (for example, HUST, NEU, VNU, FTU, EPU, and RMIT each have distinct grade thresholds and weights).

avg_gpa provides a unified, accurate web application where students can calculate semester GPA, track cumulative multi-semester CPA, import/export transcripts via Excel, simulate future graduation targets, and receive personalized study strategies from Google Gemini 3.8 Flash.

Technology Stack

HTML5 Tailwind CSS JavaScript (ES6+) SheetJS (xlsx 0.18.5) Netlify Serverless Functions Google Gemini 3.8 Flash API LocalStorage State

Key Technical Features

  • 30+ University Grading Scales: Built-in accurate conversion rules for EPU, HUST, NEU, VNU, FTU, PTIT, HaUI, RMIT, FPTU, and more, with instant search and live conversion table preview.
  • 3 Flexible Input Modes & Per-Course Weights: Supports Component Scores (2 or 3 components with customizable % weights per course), Direct 10-point Score, or Letter Grade selection, with real-time badge previews on every row.
  • Multi-Semester CPA & Auto-Save: Add, rename, or delete semesters while automatically persisting state in localStorage (avg_gpa_app_state_v2).
  • Excel (.xlsx) Import & Export: Parse 3-column or 4-column student transcripts via SheetJS, download sample templates, and export comprehensive multi-semester GPA/CPA summary workbooks.
  • Graduation CPA Goal Calculator: Computes the exact minimum GPA required across remaining credits to achieve Distinction (3.60), Very Good (3.20), or Good (2.50), alerting students when course retakes are mathematically necessary.
  • Serverless Gemini 3.8 Flash AI Advisor: Securely proxies transcript context through a Netlify Function (/.netlify/functions/call-gemini) and renders AI feedback using a custom XSS-safe Markdown parser.
