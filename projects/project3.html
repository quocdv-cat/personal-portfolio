Personal Developer Portfolio Hub

A lightweight, zero-dependency, security-hardened personal portfolio designed to showcase software engineering projects, technical skills, and interactive web applications.

Production Ready Role: Frontend Architect & Developer Zero Build Step / Pure Web Standards

Repository Architecture

personal-portfolio-main/
├── index.html          # Main portfolio entry point
├── styles.css          # CSS Custom Properties & responsive design system
├── script.js           # Theme manager, mobile nav, filter & scroll-spy
├── images/             # Profile photo & SVG project thumbnails
└── projects/
    ├── project1.html   # AIO-down case study page
    ├── project2.html   # avg_gpa case study page
    ├── project3.html   # Portfolio architecture page
    ├── AIO-down/       # Integrated Python Telegram Bot source
    └── avg_gpa/        # Integrated GPA/CPA Calculator web app

Project Overview

Designed as a central engineering hub during my Software Engineering studies at Electric Power University (EPU), this portfolio organizes my software projects, technical stack, and contact channels in a clean, fast-loading interface.

Instead of relying on heavy frontend frameworks for a content-driven portfolio, the system uses semantic HTML5, modern CSS Grid/Flexbox with CSS Custom Properties, and modular Vanilla JavaScript—achieving instant page loads while hosting standalone sub-projects directly inside the ./projects/ directory.

Technologies Used

Semantic HTML5 CSS3 Custom Properties CSS Grid & Flexbox Vanilla JavaScript (ES6+) Content Security Policy (CSP) FormSubmit Integration

Key Architectural Features

  • Persistent Dark & Light Theme System: Respects OS-level prefers-color-scheme preferences by default while allowing manual one-click toggling saved in localStorage.
  • Interactive Project Filtering & Case Studies: Filter projects by domain (Web & AI, Python & Bot, Frontend UI) and inspect dedicated architectural breakdown pages for each project.
  • Sub-Project Integration: Hosts both standalone web applications (avg_gpa) and backend/bot repositories (AIO-down) under ./projects/ without dependency collisions.
  • Responsive Sidebar & Scroll-Spy Navigation: Fixed developer profile sidebar on desktop that adapts into a collapsible accessible navigation bar on tablet and mobile viewports.
  • Content Security Policy (CSP) Hardening: Restricts script, style, font, and connection origins to trusted endpoints only.
